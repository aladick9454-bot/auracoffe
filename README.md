# AURA COFFEE — полный учебный лендинг

## Состав
- `index.html`, `style.css`, `script.js` — клиентская часть.
- `assets/` — локальные фотографии.
- `server.js` — Express API для запросов бронирования и отправки в Telegram.
- `.env.example` — шаблон настроек. Не публикуйте настоящий `.env`.

## Запуск интерфейса
Откройте `index.html` в браузере или через Live Server. Меню, анимации, галерея и навигация работают без сервера. **Отправка бронирований через Live Server не работает**.

## Запуск с Telegram
1. Установите Node.js версии 18+.
2. В терминале в папке проекта выполните `npm install`.
3. Создайте `.env` на основе `.env.example`.
4. Создайте бота через @BotFather и вставьте токен в `TELEGRAM_BOT_TOKEN`.
5. Напишите своему боту, определите ID чата и вставьте его в `TELEGRAM_CHAT_ID`.
6. Выполните `npm start`.
7. Откройте **http://localhost:3000** (не Live Server) и отправьте тестовую заявку.
8. Проверьте `http://localhost:3000/api/health`: поле `telegramConfigured` должно быть `true`.

## Публикация
Фронтенд можно разместить на статическом хостинге, но для формы понадобится отдельный сервер и настройка URL API. Самый простой путь — разместить **весь проект целиком на Node.js-хостинге**, указав `npm install` / `npm start` и добавив секреты через переменные окружения. Не загружайте `.env` в GitHub. HTTPS обязателен для реальных заявок.

## Важно перед реальным запуском
- Кофейня, меню и цены демонстрационные. Замените их данными клиента.
- Укажите реальные адрес, контакты, часы работы, условия бронирования и политику обработки персональных данных.
- Формы создают **запрос на бронирование**, а не подтверждают свободный столик.
- Сервер содержит базовую валидацию, honeypot и ограничение запросов в памяти. Для высоконагруженного коммерческого использования нужны более устойчивые ограничения, мониторинг, хранение заявок/резервирование и юридически корректное оформление обработки данных.
- Фотографии являются учебными визуальными материалами, а не фотографиями настоящей кофейни.
