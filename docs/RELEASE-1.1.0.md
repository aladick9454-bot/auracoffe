
# AURA COFFEE v1.1.0

## Release overview

AURA COFFEE is a full-stack demonstration
project for a coffee shop website and
business automation platform.

Version 1.1.0 focuses on operational
reliability, security, monitoring,
recovery and commercial readiness.

## Product capabilities

- Responsive public website.
- Online booking requests.
- PostgreSQL data storage.
- Business process automation with n8n.
- Administrative monitoring dashboard.
- API protection and security monitoring.
- Automated cloud availability monitoring.
- Incident detection and recovery monitoring.
- Database backup and isolated restore testing.
- Automated project validation.
- Operational and maintenance documentation.

## Technology stack

The application is deployed using Render.

Production configuration is managed through
environment variables and external services.

No production credentials are included
in the source code.
